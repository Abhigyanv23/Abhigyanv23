<h3>Edge-AI Wearable Safety System</h3>

<img src="https://img.shields.io/badge/CAPSTONE-0d1117?style=flat-square&labelColor=ffffff&color=0d1117" />

</div>

Smart helmet and smart vest for construction workers. An ESP32-S3 runs an on-device LSTM fall detector (TFLite Micro); a Raspberry Pi 5 vest adds heart rate, SpO2, temperature and a camera, and streams everything to a Next.js dashboard.

Team of four. The README documents the limits too: about 40% precision and a 22% false-positive rate at the current baseline.

**Built with**

`ESP32` `TFLite Micro` `Raspberry Pi` `Next.js` `Socket.IO`
